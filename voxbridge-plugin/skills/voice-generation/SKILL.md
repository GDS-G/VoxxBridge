# VoxBridge voice generation

VoxBridge is provider-neutral. Never assume a specific fictional universe, character set, business, or content workflow.

When the VoxBridge MCP gateway is connected:

1. Call `list_providers` when provider availability or capabilities are unknown.
2. Call `list_voices` before generation when the user has not provided an exact voice ID.
3. Call `generate_speech` using the user's requested provider, `voice_id`, language, model, `output_format`, speed, performance direction, and `delivery` choice.
4. Map delivery intent explicitly: use `playback` for “recite,” “read aloud,” “play,” or “preview”; use `file` for “download,” “save,” or “give me the audio file”; use `both` when the user requests both. When no delivery preference is stated, use the gateway default, `both`.
5. Map natural-language performance direction into `instructions` only when `list_providers` reports support. Hume currently requires `model="octave-1"` for acting direction; OpenAI excludes `tts-1` and `tts-1-hd`. Respect each provider's `instructions_note`.
6. Use `options_json` only for documented provider-specific controls. Do not invent parameters.
7. Respect the selected provider's reported `speed_range`, formats, `file_delivery_formats`, character limit, allowed options, and `control_notes`. Raw PCM is playback-only in this developer alpha; use WAV when the user selects `file` or `both`, explaining the container change if they explicitly asked for PCM.
8. Surface only the representation(s) the user selected. `playback` returns immediate audio, `file` returns the named binary audio-file resource with its Download control, and `both` returns both from one provider generation. Identify every result as synthetic AI-generated audio and preserve the requested output format.
9. If a provider is not configured, state that clearly and offer another connected provider rather than silently switching.
10. If the user asks to compare providers, keep the source text and requested performance direction as consistent as each provider permits.
11. Do not regenerate speech merely to change presentation: when `both` is selected, the player and file reference resolve to the same generated bytes.
12. For `file` or `both`, use the gateway's MCP App Download control when the host supports `ui/download-file`. If the host lacks that capability, state the limitation clearly and preserve the standard MCP resource link instead of claiming a file was saved.
13. VoxBridge currently exposes text-to-speech and voice listing only. Do not claim voice cloning or speech-to-speech is available.

Initial providers: ElevenLabs, Hume AI, Cartesia, Resemble AI, OpenAI, Deepgram, Google Cloud Text-to-Speech, and Microsoft Azure Speech.
