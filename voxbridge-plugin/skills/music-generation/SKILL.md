# VoxBridge music generation

Use this workflow only for new ElevenLabs Music generations exposed by VoxBridge. It is separate from speech synthesis and multi-voice dialogue.

When the VoxBridge MCP gateway is connected:

1. Call `list_providers` when availability is unknown. Continue only when `elevenlabs` is configured and reports `music_generation`; do not silently substitute another provider. ElevenLabs Music API access can also depend on the user's current subscription and entitlements.
2. Call `generate_music` exactly once for the requested track. Music generation can consume paid provider quota, so do not generate speculative samples, variations, or retries the user did not request.
3. Provide exactly one source:
   - Use `prompt` for a natural-language description, up to 4,100 characters.
   - Use `composition_plan_json` for one complete, valid, non-empty ElevenLabs composition-plan JSON object serialized as a string, up to 40,000 characters. Do not send both inputs. Prefer `prompt` unless the user provides or explicitly requests a structured plan.
4. Default to `model="music_v2_5"`. Use `music_v1` or `music_v2` only when the user explicitly requests it or a documented compatibility requirement makes it necessary.
5. In prompt mode, pass `music_length_ms` only when the user requests a duration. The accepted range is 3,000 through 600,000 milliseconds. When omitted, VoxBridge deliberately generates 30,000 milliseconds rather than leaving the potentially billable duration unbounded. `force_instrumental` is also prompt-only.
6. In composition-plan mode, `seed` is optional and must be an integer from 0 through 2,147,483,647. It can improve consistency but does not promise bit-for-bit reproduction. `respect_sections_durations` defaults to `true`; for Music v2 and v2.5 the provider always enforces section durations. Do not use duration or `force_instrumental` with a composition plan.
7. Pass `finetune_id` only when the user supplies or selects an eligible ElevenLabs Music finetune. Pass `sign_with_c2pa=true` only when the user requests C2PA signing. C2PA is valid for this workflow because VoxBridge currently emits MP3 only.
8. Keep `output_format="mp3"`. This release does not expose WAV music output even if another ElevenLabs surface supports it.
9. Map delivery intent explicitly: use `playback` for “play,” “listen,” or “preview”; use `file` for “download,” “save,” or “give me the track”; use `both` when both are requested. When unspecified, use the gateway default, `both`.
10. `file` returns a short-lived named MP3 resource; `playback` returns inline playable audio; `both` provides the player plus the same downloadable file. Do not generate again merely to change presentation. The gateway's short-window replay guard may reuse an identical host approval retry, but that safeguard is not permission to issue a deliberate duplicate call.
11. For a local save, use the MCP App Download control when the host supports `ui/download-file`. Downloading does not itself attach the file to the conversation. The separate **Add file to ChatGPT** action materializes the exact existing MP3, verifies its bytes, and sends the preserved embedded resource through `ui/update-model-context`; the host may request approval. Do not claim reusable-library persistence, a permanent file ID, or acceptance by every downstream editor.
12. When ChatGPT or another compatible tool needs the exact generated bytes, call `materialize_audio_file` with the exact `materialize_resource_uri` returned by `generate_music`. If the host hides it, use the exact generated `file_name` instead. Supply exactly one locator, never infer or alter it, and never regenerate solely to obtain an attachment.
13. If generation succeeds but delivery fails, explain that provider charges may already apply and do not retry without the user's direction. If ElevenLabs rejects account access, content, or settings, report that specific failure without weakening the requested safeguards.

Treat every result as synthetic AI-generated music. Do not promise copyright ownership, royalty-free status, commercial clearance, or a particular license. The user remains responsible for the current ElevenLabs Music Terms, their subscription tier, applicable law, and rights in prompts, lyrics, samples, finetune data, and downstream use. Avoid requests that copy copyrighted lyrics or target a protected song, recording, or living artist too closely; offer a high-level genre, instrumentation, era, mood, and structure description instead.

This VoxBridge release supports text-prompt and composition-plan generation only. It does **not** expose music upload or audio-reference input, inpainting or editing an existing track, video-to-music, stem separation, finetune creation/training, or post-generation section editing. Do not imply that any of those operations are available through this plugin.
